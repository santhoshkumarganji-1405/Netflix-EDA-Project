# 📊 Netflix Movies & TV Shows - Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset to uncover patterns, trends, and insights from the platform's content library. Using Python and popular data analysis libraries, the project explores content distribution, ratings, release trends, genres, and country-wise contributions.

The goal of this project is to develop data exploration and analytical skills by transforming raw data into meaningful insights through statistical analysis and visualizations.

---

## 🎯 Objectives

* Understand the structure of a real-world dataset.
* Perform data cleaning and preprocessing.
* Generate statistical summaries.
* Explore patterns and trends in Netflix content.
* Create informative visualizations.
* Identify key insights and influencing factors.
* Present findings in a structured and understandable manner.

## 📂 Dataset

Dataset Used: **Netflix Movies and TV Shows Dataset**

Source: Kaggle

Dataset File:

```text

```

The dataset contains information about Netflix content, including:

* Title
* Type (Movie/TV Show)
* Director
* Cast
* Country
* Date Added
* Release Year
* Rating
* Duration
* Genre

## 📈 Key Insights

* Movies constitute the majority of Netflix content.
* Significant growth in content additions occurred after 2015.
* The United States contributes the highest number of titles.
* TV-MA is among the most common content ratings.
* International Movies and Dramas are highly represented genres.
